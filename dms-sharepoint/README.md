# Área DMS SharePoint

Esta carpeta documenta la implantación del sistema documental:

- `estructura-documental/`: bibliotecas, taxonomías y jerarquías.
- `metadatos/`: esquemas, tipos de contenido y campos.
- `permisos/`: roles, grupos y matriz de permisos.

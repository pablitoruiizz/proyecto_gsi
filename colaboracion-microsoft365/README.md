# Área de Colaboración Microsoft 365

Documentación y configuración de herramientas colaborativas:

- `teams/`: equipos, canales, normas y gobierno.
- `planner/`: planes, buckets y seguimiento de tareas.
- `power-automate/`: flujos y automatizaciones.
- `powerapps/`: apps internas y especificaciones.

## Buenas prácticas
- Registrar objetivo, configuración y permisos por artefacto.
- Mantener trazabilidad con historias de usuario y sprints.

# Maquetas / Mockups

Guardar en esta carpeta maquetas de interfaz y prototipos de baja/alta fidelidad.

## Convenciones
- Nombrar archivos por módulo y pantalla: `modulo-pantalla-version.ext`
- Incluir versión y fecha en el documento asociado.
- Añadir breve contexto en Markdown cuando sea necesario.

## Formatos recomendados
- `.png`, `.jpg`, `.svg` (ligeros)
- `.pdf` (entregables)
- `.md` (descripción y decisiones de UX)

> Evitar incluir datos reales del cliente en capturas.

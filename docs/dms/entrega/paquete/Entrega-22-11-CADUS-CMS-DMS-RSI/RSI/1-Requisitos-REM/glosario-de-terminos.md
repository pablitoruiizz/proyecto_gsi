# Glosario de términos · Red Social Interna del CADUS

Generado desde `scripts/remus/rsi_data.json`; es el mismo glosario que lleva `RSI.rem`.

| Término | Significado |
|---|---|
| Equipo | En Microsoft Teams, el espacio de trabajo de un grupo de personas, con sus canales, archivos y herramientas. |
| Grupo y subgrupo | Conjunto de personas del CADUS con un mismo papel (Ejecutiva, Delegaciones, Asamblea). Un subgrupo es una parte de un grupo (por ejemplo, la delegación de un centro). En Teams, cada grupo es un equipo y cada subgrupo es un canal privado de ese equipo. |
| Canal | Conversación temática dentro de un equipo. Puede ser estándar (lo ve todo el equipo) o privado (solo las personas invitadas). |
| Herramienta | Aplicación que se ancla a un canal: Archivos (SharePoint), Calendario, Planner, Forms, y automatizaciones de Power Automate o aplicaciones de PowerApps. |
| Rol | Papel de una persona en el equipo: propietario (administra), miembro (participa) o invitado (acceso limitado). |
| Permiso | Acción que un rol puede hacer sobre un grupo o un canal: leer, publicar, gestionar canales o administrar miembros. |
| Planner | Herramienta de Microsoft 365 para repartir tareas en planes con cubos, responsables y fechas. |
| Power Automate | Herramienta de Microsoft 365 para crear flujos automáticos, por ejemplo avisos cuando se asigna una tarea. |
| PowerApps | Herramienta de Microsoft 365 para crear aplicaciones sencillas sobre los datos del equipo. |

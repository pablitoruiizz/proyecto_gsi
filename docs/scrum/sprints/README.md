# Organización de Sprints

Cada sprint debe tener una carpeta propia con nomenclatura:

- `sprint-01/`
- `sprint-02/`
- `sprint-XX/`

Contenido recomendado por sprint:
- `sprint-backlog.md` (objetivo, historias comprometidas, tareas)
- `daily-notes.md` (bloqueos y avances)
- `review.md` (resultado de Sprint Review)
- `retrospective.md` (mejoras y acciones)

## Plantilla mínima de Sprint Backlog
- Objetivo del sprint
- Historias incluidas (ID + estado)
- Capacidad del equipo
- Riesgos y mitigación

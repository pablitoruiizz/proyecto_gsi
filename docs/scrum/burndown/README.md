# Burndown

En esta carpeta se almacenan los artefactos de seguimiento de avance por sprint.

Formatos aceptados:
- `.csv` (datos diarios)
- `.md` (resumen textual)
- `.png`/`.svg` (gráfica ligera)

## Recomendación de actualización
1. Registrar esfuerzo pendiente diario.
2. Actualizar gráfica al menos en cada Daily.
3. Referenciar la fuente de datos (issue tracker o backlog).
4. Añadir interpretación breve al cierre del sprint.

> Evitar subir archivos pesados o con datos sensibles del cliente.
